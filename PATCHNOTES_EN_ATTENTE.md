# Modifications en attente de patch note

Règle : on ne publie un patch note (dans `patchnotes.js`) qu'à partir de **5 modifications** visibles par les joueurs.
Tant qu'il y en a moins de 5, on les note ici. Quand on arrive à 5, on les met toutes dans un nouveau patch note, puis on vide cette liste.
(Le patch note envoie une notification à tout le monde, c'est pour ça qu'on les regroupe.)
